## 一、AI 代投是什么

把产品投到造梦橱窗有两条路：

1. **网页自己投**：登录 zm94.com → 右上角「投稿」→ 逐项填表。
2. **AI 代投**：设置 → 「AI 发布密钥」→ 生成一串 `pk` 密钥 → 把密钥和产品资料交给你的 AI 助手，它照着 skill.md 调投稿接口，替你完成投稿。

AI 代投的好处：不用填表；资料零散也没关系（一段话、一篇文章、一个链接都能整理成规范投稿）；产品多时可以批量投。

---

## 二、第一步：拿密钥

登录 → 右上角菜单 → 设置 → 「AI 发布密钥」→ 生成。

- 形如 `pk` 开头的 48 位串，**只有生成那一刻能看到完整版**，复制好交给你的 AI
- 密钥只对「投稿」这一个接口生效：改不了密码、看不了私信、动不了你的账号
- 感觉泄露了？回设置页「换一把新钥匙」，旧钥匙立即作废

---

## 三、第二步：挑一个「能干活」的 AI 应用

判断标准只有一条：**它能不能替你发 HTTP 请求**（有联网访问、代码执行、HTTP 插件之类的能力）。这个 skill 本质就是"照着说明书调一个接口"，不需要任何特殊集成。

✅ **能用的（常见类型）**：

| 类型 | 例子 |
|---|---|
| Agent / 编程助手 | WorkBuddy、Claude Code、CodeBuddy、Cursor、Windsurf、Trae 等 |
| 开了工具的通用 AI | ChatGPT（GPTs / 联网 / 代码执行）、扣子（Coze）配了 HTTP 插件的 bot、Dify 工作流带 HTTP 节点 |
| 能跑终端命令的 AI | 任何带命令行 / 代码沙箱的助手 |

❌ **用不了的**：

- 纯聊天型应用：没开任何工具的网页版对话、多数手机 App 的默认聊天模式
- 表现很有辨识度：它会说「我没法直接发外部接口调用」，然后把一段 curl 命令还给你，让你自己跑——这就是没有工具执行能力的信号，换上面清单里的应用

💡 **快速判断法**：直接问它一句「你能替我发 HTTP 请求 / 跑命令吗？」，答"能"就能用，答"不能"就换。

---

## 四、第三步：把 skill 交给它（三选一）

**方式 1：发链接（推荐）**——能联网的 AI 直接拉最新版：

> 请打开 <https://zm94.com/skill.md> 读一遍，按它的流程替我把我的产品投稿到「造梦橱窗」。我的密钥是 pk……，产品资料如下：……

**方式 2：粘贴全文**——AI 打不开外链时，把 skill.md 的全文复制进对话。

**方式 3：上传文件**——把 skill.md 存成文件发给它，效果同上。

话术里三样东西缺一不可：skill 链接（或全文）、你的密钥、产品资料。

---

## 五、只有一篇文章 / 一大段话？也能行

这是 AI 代投最省事的地方：**你不用自己填表**。文章链接、Markdown、口语化的一大段介绍、产品主页上的文字，直接丢给 AI，它会按 skill.md 的字段规范解析：

| 原文里的东西 | 解析成的投稿字段 |
|---|---|
| 产品名 | `wname` |
| 「是什么」那一句 | `wtag`（也是 title 的后半段） |
| 详细介绍段落 | `prompt`（自动整理成轻量 Markdown） |
| 网址 | `link` |
| 各平台链接（App Store / APK / 仓库…） | `links` / `repo` |
| 截图、海报的图片链接 | `imageUrl` / `imageUrls` |
| 反复出现的功能词 | `keywords` |
| 它是个什么类型的东西 | `types` / `categories` |

**举个例子**——你丢给它一段这样的：

> 帮我把这个投到造梦橱窗。产品叫"墨鱼日记"，就是给写小说的人用的，资料全存本地、不联网也能写，支持 Markdown 和版本历史，开源的，仓库在 github.com/example/moyu-diary，网站是 https://moyu.example.com 。详细介绍我贴在下面：……

它会解析出一份**摘要给你过目**（标题 / 形态 / 分类 / 简介），缺的东西它会**问你，不会瞎编**：

- **封面图** → 必填，没有它会向你要
- **形态 / 分类** → 从站点实时清单里选（每次投稿前先拉一次）
- **《作品规范》** → 必须你亲口同意，它才会带 `agreeRules=1` 提交；你没点头它不能替你勾
- **开源** → 顺手把仓库地址带上，还能按 star 数拿开源收录奖励

你点头它才发；发完把作品页链接（`zm94.com/w/…`）和审核状态告诉你，到此为止。

## 六、图片从哪来

- **封面是硬要求**。AI 手里有公网图片直链（jpg / png / gif / webp，≤10MB）最省事，服务端会代抓
- **只有本地图片**？让它走 skill.md 的「方式 B」multipart 直传文件
- **只有网页截图**？把图先传到任意稳定图床（GitHub、对象存储、你自己的站点）再给它链接；带有效期签名、很快过期的临时链接不行

---

## 七、密钥安全三句话

1. 密钥只对投稿生效，最坏情况 = 有人以你的名义投稿（还得过机器初审）。
2. 别写进公开 README、博客、群聊；发给**你的** AI 助手没问题，发给不相干的第三方不行。
3. 贴到过"不对劲"的地方 → 立刻回设置页换一把新钥匙。

## 八、常见问题

**我的 AI 说「我没法发外部接口调用」？**
它没有工具执行能力，按第三节的标准换一个应用。

**投稿后显示「审核中」？**
密钥投稿一律先过一道机器初审，通过即自动上线（通常几秒到几分钟），没过的转人工，一般当天内处理。别反复重投同一件。

**有数量限制吗？**
密钥投稿每小时最多 8 件；投稿灯火奖励照发，首件更高。

**AI 代投的和自己投的有区别吗？**
都记在你账号名下，灯火奖励一样；区别只是 AI 代投多过一道机器初审。
