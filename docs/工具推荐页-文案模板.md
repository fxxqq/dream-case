用途：单独一页，放在造梦橱窗里。只推荐本站作者真会用得上的服务，不收作者钱、不担保交易，佣金由各家平台自己结算。

> 使用说明（发布前删掉这一段）：
> 1. 所有 `{你的XX链接}` 换成后台拿到的真实推广链接；没有推广链接的工具就放官网首页，别硬塞。
> 2. 比例和规则以各家官网当前页面为准，本文里标「待核实」的先别写进公开页面。
> 3. 文案保持客观，不要出现「点链接我赚钱」「帮我冲业绩」这类话。

## 页面正文

### 标题

创作者常用工具推荐

### 开场白

做小工具和 Agent 的人，挑服务这件事实在挺费时间的。这里放了几个常见的、也经常在作品简介里看到的，按用途分了一下。每个都写了一句什么场景适合用，你自己看着挑就行。

下面这些链接是各家的官网或注册页，注册后怎么用、怎么收费都以平台自己写的为准。除了扣子和硅基流动，其余都是海外服务，界面和文档基本以英文为主，付费也要能走国际支付的卡——这点先说在前面。造梦橱窗不经手任何付款，也不对服务本身负责。

### 部署托管

**Railway**（`{你的Railway链接}`）

海外平台，界面和文档都是英文。小项目、Agent 后端、带数据库的小服务都能直接丢上去，从 GitHub 仓库到跑起来很快。按用量计费，注册送 20 美元额度，够试一阵子。付费要能走国际支付的卡。推荐链接注册的话，我们会在你付费账单里拿到一点分成，不影响你自己的价格。

**Vercel**（`{你的Vercel链接}`）

Next.js 和前端静态站的老熟人，部署快、预览环境好用。有付费方案，具体额度看官网。

**Netlify**（`{你的Netlify链接}`）

静态页面、纯前端小工具放这里很省事，表单和边缘函数也有。

**Supabase**（`{你的Supabase链接}`）

开源后端，Postgres 数据库、登录、文件存储一套齐。做带账号和小数据库的 Agent 很常见，免费档够起步。

### AI Agent / 低代码

**Dify**（`{你的Dify链接}`）

搭工作流和 Agent 用得多，RAG、插件、发布成 Web 应用都在一个界面里。本站不少作品就是拿它做的。有免费额度和付费方案，按工作空间算。

**扣子 Coze**（`{你的Coze链接}`）

国内用的人多，做聊天机器人和工作流上手快。规则变动比较频繁，具体优惠看它现在的活动页。

**Taskade**（`{你的Taskade链接}`）

偏协作和任务方向的 AI Agent，适合把团队流程和 AI 放一起的场景。

### 大模型 API

**OpenRouter**（`{你的OpenRouter链接}`）

一个 API key 调几百个模型，按量付费、不用订阅，模型挂了会自动切别家。写 Agent 的时候省很多事。

**硅基流动 SiliconFlow**（`{你的SiliconFlow链接}`）

国内的大模型 API，网络和付款都方便一些。现在主要是内容激励，先当个可选方案了解就行。

### 域名 / 主机

**Namecheap**（`{你的Namecheap链接}`）

买域名和证书，开发者圈子里用得挺多，价格一直比较实在。

**Hostinger**（`{你的Hostinger链接}`）

海外主机，适合要完整建站环境的场景，首购价格比较划算。

**Cloudflare**（`{你的Cloudflare链接}`）

CDN、DNS、免费证书这些基础能力就不多说了，基本是每个站都会用一层的东西。

### 想一次看完的

如果不想一家家申请，PartnerStack 上能把 Vercel、Supabase 这类 SaaS 的推广链接集中管理；Awin、Impact 上品类更多，审核会严一些。这部分是给想自己长期做推荐的人看的，普通访客不用管。

### 页尾说明（固定保留）

这些是第三方服务，我们只做推荐，交易、付款、售后都在平台那边。作品用不用这些工具完全由作者自己决定，不影响作品在站里的展示和排序。链接指向哪里、平台给不给优惠，也请以对方当前页面为准。

## 给作者的可选字段文案

放在作品提交/编辑页，默认不勾，文案别写太长：

> 本项目用到的服务（选填）
> 如果作品用了下面的服务，可以勾一下，简介里会带一行说明。不勾也没关系，不影响作品展示。
> □ Railway　□ Vercel　□ Supabase　□ Dify　□ OpenRouter　□ 其他：______

作者勾了以后，作品简介下方只加一行很轻的字，比如「用了 Dify 搭工作流」，不要弹窗、不要角标、不要强制。链接统一走本站推荐页的对应条目，不要给作者在作品里插外链的权限（避免被当成广告位）。

## 摆放方式

单独一页最省事，导航里放「工具推荐」入口即可。作者自愿字段是第二步，等页面跑一阵子、确认有人从这儿注册了再加也不迟。两件事别一起上，先看看链接点得动不动。

不要做的事：不要在作品列表里插推广卡、不要给作者 Grammarly 式的「开启推广」开关、不要把推荐位和榜单排序沾上关系。
